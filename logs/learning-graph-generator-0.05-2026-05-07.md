- Modern resin: Mono LCD Resolution, Large-Format Resin

- Connectivity: Wi-Fi Connected Printer, Print Camera Monitoring, AI Failure Detection, OctoPrint Server, Mainsail Web Interface
- Enclosures: Heated Chamber, Enclosed Printer
- Printer ecosystems: Bambu Lab Printers, Prusa Printers, Creality Printers, Voron DIY Project
- Composite filaments: Carbon Fiber Filament, Wood Fill Filament, Metal Fill Filament
- Specialized print modes: Vase Mode, Fuzzy Skin

Also linked the previously orphaned **Algebra Basics** (concept 1) by adding it as a dependency of **Tolerance Allowances** (concept 162) — algebra is genuinely needed for tolerance arithmetic.

## Known caveat

`./validate-learning-graph.sh learning-graph.json` reports an error on `groups.WORK.color` because the schema (`learning-graph-schema.json` shipped with the skill) expects `color` to be a nested object, while `csv-to-json.py v0.04` outputs the flat string format that the vis-network graph viewer actually consumes. The JSON is correct for downstream tooling — the schema is out of sync with the script. No action needed unless the schema is updated.
