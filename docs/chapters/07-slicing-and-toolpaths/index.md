# Slicing, G-code, and Toolpaths

## Summary

This chapter covers the slicer software that turns CAD geometry into machine instructions. Students learn the G-code that printers actually execute, every key slicer parameter (layer height, infill density and pattern, wall count, print speed, retraction, temperatures, cooling fan, adhesion type), how supports and skirts/brims/rafts work, how slicer profiles are constructed and reused, and specialized print modes (vase mode, fuzzy skin). Cloud slicing is introduced as a modern delivery model.
