# References: FDM Printer Hardware and Operation

1. [Fused deposition modeling](https://en.wikipedia.org/wiki/Fused_deposition_modeling) - Wikipedia - Comprehensive technical overview of FDM hardware including hotend, nozzle, heat break, extruder, motion system, build platform, and controller board components.

2. [RepRap project](https://en.wikipedia.org/wiki/RepRap_project) - Wikipedia - History of the open-source RepRap movement that standardized most FDM hardware designs — Cartesian, delta, and CoreXY — still found in desktop printers today.

3. [Stepper motor](https://en.wikipedia.org/wiki/Stepper_motor) - Wikipedia - Technical explanation of stepper motor operation, microstepping resolution, holding torque, and how these motors translate G-code coordinates into precise physical motion.

4. Make: 3D Printing — Anna Kaziunas France — Maker Media, 2014 — Hands-on guide to FDM printer hardware covering assembly, bed leveling, first-layer calibration, nozzle changes, and routine maintenance with clear procedural steps.

5. The 3D Printing Handbook — Ben Redwood, Filemon Schöffer, Brian Garret — 3D Hubs, 2017 — Professional reference covering FDM hardware design decisions, material-hardware interactions, and process parameters for both desktop and industrial machines.

6. [RepRap](https://reprap.org/wiki/RepRap) - RepRap Project - The original open-source FDM hardware documentation with detailed guides on extruder variants (direct vs. Bowden), hotend designs, heated bed wiring, and motion system configurations.

7. [What is FDM 3D printing?](https://www.hubs.com/knowledge-base/what-is-fdm-3d-printing/) - Hubs (Protolabs Network) - Clear overview of how all FDM hardware components work together — from filament loading through final layer deposition — with desktop vs. industrial comparisons.

8. [Print quality category](https://help.prusa3d.com/category/print-quality_225) - Prusa Knowledge Base - Hardware troubleshooting articles covering bed leveling procedures, first-layer diagnosis, nozzle clogs, extruder calibration, and motion system maintenance.

9. [3D printer calibration guide](https://teachingtechyt.github.io/calibration.html) - Teaching Tech - Systematic hardware calibration resource covering extruder e-steps, PID temperature tuning, bed mesh leveling, and motion system checks with custom G-code generators.

10. [Printables](https://www.printables.com) - Prusa Research - Community hub where users share printable hardware upgrades, modified extruder designs, calibration tools, and maintenance jigs for popular FDM printer platforms.
